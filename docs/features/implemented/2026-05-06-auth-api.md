# 用户认证

## 状态

implemented

## 功能摘要

提供用户注册、登录、当前用户资料查询和当前用户密码修改能力。

## 最终实现范围

- `POST /api/v1/users`：注册用户，密码使用 `pbkdf2_sha256` 哈希，成功后返回 access token。
- `POST /api/v1/sessions`：使用 email 和 password 登录，成功后返回 access token。
- `GET /api/v1/users/me`：通过 Bearer token 获取当前用户资料。
- `PATCH /api/v1/users/me/password`：验证旧密码后更新为新密码。
- JWT payload 包含 `sub`、`type="access"`、`iat` 和 `exp`。
- 非 active 用户无法登录或访问受保护接口。

## 使用方式

1. 调用 `POST /api/v1/users` 注册并取得 token。
2. 后续受保护接口使用 `Authorization: Bearer <token>`。
3. token 过期时间由 `APP_ACCESS_TOKEN_EXPIRE_MINUTES` 控制。

## 测试结果

- `tests/test_auth_api.py` 覆盖注册、登录、当前用户查询和修改密码流程。
- 该测试需要 `DATABASE_URL` 指向可用数据库。

## 已知限制

- 当前没有 refresh token。
- 当前没有邮箱验证、找回密码或用户禁用管理 API。

## 后续改进方向

- 增加 refresh token、注销、邮箱验证和密码重置流程。
- 增加更明确的认证错误码文档。
